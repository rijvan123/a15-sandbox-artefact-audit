## 9. Authors' decisions of 4 November 2026

1. **Aliases.** Proposal in `alias_review_2026-11-04.csv` and `alias_table_proposed.json`: 15 accepted, 4 uncertain (left out), 64 rejected. Four add a shared family in all three origins: redlinestealer = redline (MELD 394 traces, WinMET 4,438), snakekeylogger = snakelogger (1,045; 365), remcosrat = remcos (663; 174), quasarrat = quasar (386; 61). Every entry renames a MELD name to the WinMET name, so the WinMET split is unchanged. Applied only once the authors save it as `alias_table.json`.
2. **K4.** Run the pre-registered ClarAVy check on binaries shared with EMBER2024. The rule keeps a shared family only if, in each installation where it has at least 10 shared binaries with a ClarAVy label of confidence >= 0.7, at least 80% agree; families with fewer stay "unverified" and are kept as a stated limitation. The confidence threshold was set before any agreement was computed.
3. **Dry run.** Changed as above and to be re-run; the 3 November dry run also drew WinMET traces that the split puts in the test part (its model learned nothing from them), which the new design excludes.
4. **Compute (K6).** No GPU is available (no institutional GPU; Claude's environments are CPU-only). Chosen plan: about 72 CPU-hours on the authors' PC (estimated; the new dry run re-measures it at L = 256).
